# 水槽ログ（AquaLog）

海水水槽の管理用 Android アプリ。

- **作業ログ**：換水・足し水・掃除などを日付つきで記録
- **水質**：比重・水温・NO3・PO4・KH・Ca・Mg を記録してグラフ表示
- **生体台帳**：導入日・購入先・値段・写真・状態（飼育中／移動済み／死亡など）
- **リマインド**：「換水 14日ごと」などを設定し、毎日19時ごろに期限のものを通知。
  連動する作業を記録すると自動で完了扱いになる

## ビルド

`main` に push すると GitHub Actions がビルドし、Releases に APK を置く。
スマホで Releases の最新版を開いて APK をダウンロード → インストール。

署名鍵（`app/aqualog.keystore`）は固定なので、上書きインストールしてもデータは消えない。
